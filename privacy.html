Privacy

你的笔记，留在你的浏览器里

Get2MD 是本地优先的导出工具。它不做账号系统，不做数据库，也不会把你的 API Key、Client ID 或笔记内容保存到项目方服务器。

会保存什么？

为了让你下次不用重新填写，工具会把 API Key 和 Client ID 保存在当前浏览器本地。你可以随时在工具页的“接口设置”里清除本地配置。

不会保存什么？

  • 不会保存你的 Get 笔记账号。
  • 不会把 API Key 和 Client ID 写进仓库文件。
  • 不会把你的笔记内容上传到项目方数据库。
  • 不会在不同设备之间同步你的配置。

使用时注意什么？

API Key 是敏感信息。建议只在自己信任的设备和浏览器里使用，不要把真实凭证发给别人，也不要放进公开截图、教程或仓库。

如果你想检查实现方式，可以查看 GitHub 项目源码。如果发现隐私说明不清楚，也欢迎到 GitHub 反馈问题。
