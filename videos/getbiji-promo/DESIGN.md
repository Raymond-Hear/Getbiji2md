# Design System

## Overview

Get 笔记 Markdown 导出工具的视觉语言偏温暖、轻纸感、低压迫。首页使用大面积米白底色、两组淡色渐变和玻璃卡片，传达“本地优先、整理内容、安心导出”的产品气质。布局上是典型的内容型落地页加应用面板组合：上层是高信息密度的宣传文案，下层是带圆角、半透明、轻阴影的演示卡片。整体不追求科技炫光，而是强调可信、克制、耐读。

## Colors

- **Paper**: `#faf7f1` - 首页主背景，暖纸色。
- **Ink**: `#201913` - 主文字和深色图形。
- **Muted**: `#6f6254` - 次级说明文字。
- **Brand Teal**: `#246a65` - 主按钮、强调块、流程亮点。
- **Brand Teal Dark**: `#184f4b` - 深一点的品牌文字和边框语义。
- **Accent Copper**: `#a35a24` - 次强调、下载动作、暖色高光。
- **App Text**: `#24180d` - 应用页正文深色。
- **Surface Strong**: `#fffdf8` - 明亮卡片表面。
- **Surface Soft**: `#f8f1e6` - 柔和的辅助背景。

## Typography

- **Display Serif**: `Georgia`, `Times New Roman`, serif。用于首页大标题和宣传型句子。
- **UI Sans**: `Segoe UI`, `PingFang SC`, `Hiragino Sans GB`, sans-serif。用于正文、导航、按钮、表单与应用界面。
- **Heading feel**: 标题大、紧、接近杂志式排版；正文舒展，行高偏高，强调可读性。

## Elevation

界面通过半透明浅色面板、18px 左右的 backdrop blur、柔和阴影和轻边框建立层次。阴影不是重投影，而是低对比度、向下扩散的暖灰影。卡片圆角普遍较大，避免硬科技感。

## Components

- **Warm Hero Split**: 左侧大标题与卖点，右侧预览卡片，形成“宣传 + 可信演示”的首屏。
- **Glass Preview Card**: 半透明、白色高光边框、柔和阴影的演示面板。
- **Step Rail**: 用步骤或三连卡展示“配置 - 筛选 - 导出”流程。
- **Filter Dashboard**: 应用页中的知识库、标签、关键词筛选面板。
- **Download Actions**: “下载原文 / 下载 AI 总结”双按钮动作区。

## Do's and Don'ts

### Do's

- 使用暖白底色和低饱和品牌色，不要把页面做冷。
- 用大圆角、轻玻璃感和宽留白维持“整理工具”的安心感。
- 让“配置 - 筛选 - 导出”成为视频主叙事。
- 让文案读起来像产品说明，不要像空泛广告词。

### Don'ts

- 不要使用霓虹、赛博、纯黑背景。
- 不要让动画过快或过炸，节奏应稳、顺、可读。
- 不要堆太多 UI 元素同时运动，主次要清楚。
