Get Notes Export

把 Get 笔记带回你的写作流

面向 Get 用户的本地优先导出工具。同步、筛选、预览，再把原文或 AI 总结导出为 Markdown，继续放进 Obsidian、Notion 或你的本地文件夹。

当前版本是 V0.1 开源测试版。如果你遇到问题，或想一起改进体验，欢迎到 GitHub 提 PR。

先同步，再筛选

进入工具页后先同步内容，再按标签、关键词和本地已加载内容缩小范围。

先预览，再下载

打开单篇详情确认原文、AI 总结和图片，再决定下载哪一类 Markdown。

刷新后恢复现场

刷新页面后尽量恢复上次结果、筛选和详情，减少重复操作。
