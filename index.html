Features

不是只做一个下载按钮，而是一整套导出前的整理流程。

不是单纯做一个下载按钮，而是把同步、筛选、预览和导出串成一个更清楚、更可控的整理过程。

Sync first 先把笔记拉进来，再决定导出什么。

进入工具后先同步内容，再根据实际数据去筛选，而不是靠猜测记忆找文章。

适合内容量已经比较多、需要先缩小范围的人。
Preview first 原文、图片、AI 总结先看清，再做下载动作。

导出前先打开详情确认内容，减少导完才发现格式不对、图片缺失或总结不想要的情况。

让导出更像整理，不像碰运气。
Restore state 刷新页面后尽量接着上次进度继续。

工具会尽量恢复筛选、已加载结果和当前查看的内容，降低重复劳动。

更适合长时间整理资料，而不只是一次性下载。

4 steps

四步完成整理和导出

  • 1. 设置接口信息

    填写 API Key 和 Client ID。它们保存在当前浏览器本地，不会被这个网站单独上传保存。

  • 2. 同步你的笔记

    先把内容拉取下来，再看有哪些标签、知识库和文章适合继续筛选。

  • 3. 预览并确认

    点开单篇详情，先看原文、图片和 AI 总结，再决定导出原文还是总结。

  • 4. 导出 Markdown

    把你真正需要的内容带回自己的知识管理流程，不被平台页面结构卡住。

Privacy

你的笔记、凭证和使用边界，都应该说清楚。

关于会保存什么、不会保存什么，以及使用时需要注意的边界，这里先说清楚。

会保存什么？

为了让你下次不用重新填写，工具会把 API Key 和 Client ID 保存到当前浏览器本地。你可以在工具页里随时清空这些本地配置。

不会保存什么？

不会保存你的 Get 账号，不会把 API Key、Client ID 写进仓库文件，也不会把你的笔记内容上传到这个项目自己的数据库。

使用时要注意什么？

API Key 属于敏感信息。建议只在你信任的设备和浏览器里使用，不要把真实凭证发给别人，也不要放进公开截图、教程或仓库。

需要更完整的条款，也可以继续查看 隐私说明 和 GitHub 项目源码。

FAQ

遇到问题时，先在这里快速排查。

把最常遇到的几类问题集中放在这里，浏览时顺手就能查。

同步失败怎么办？
  • 确认已经填写 API Key 和 Client ID。
  • 确认当前 Get 账号具备开放平台能力和会员权限。
  • 如果刚刚失败，稍等一会儿再点击“同步我的笔记”。
看到 429 是什么意思？
429 一般表示请求过快。工具会尽量自动重试，你也可以稍等片刻后继续同步或导出。
为什么“我的知识库”可能是空的？
先同步一次笔记和知识库。如果仍然为空，可能是开放平台暂时没有返回你的个人知识库列表，但笔记列表仍然可以按标签和关键词筛选。
图片会一起导出吗？
详情页会展示图文笔记里的图片预览。导出 Markdown 时会尽量保留图片链接，方便你后续再整理。
刷新页面后还要重新加载吗？
工具会尽量恢复上次加载结果、筛选条件和当前详情。只有在你主动清理浏览器数据后，才需要重新填写接口设置。
问题还是没解决怎么办？
可以到 GitHub Issues 反馈问题。描述你正在做什么、看到什么提示、使用什么浏览器即可，不要贴出真实 API Key、Client ID 或 Token。

需要查看更多排查说明，也可以继续查看 FAQ 页面。
