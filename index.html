第一次使用怎么开始

这个工具不会自己生成接口信息。你需要先在 Get 笔记开放平台创建应用，然后把对应的 API Key 和 Client ID 填到这里。

  1. 打开 Get 笔记开放平台并登录账号
  2. 创建一个应用，获取 API Key 和 Client ID
  3. 回到这里填写并保存，系统会自动加载你的笔记
