Help Center

先解决常见问题，再找到当前功能最常用的整理入口

这里集中整理了导出时最常见的问题，以及你现在就能在 Get2MD 里用上的三类整理方式。

常见问题 知识库整理 原文与摘要 批量导出

同步失败怎么办？

  • 确认你已经填写 API Key 和 Client ID。
  • 确认当前得到大脑账号有开放平台能力和会员权限。
  • 如果刚刚失败，可以等一会儿再点“开始整理我的内容”或“重新同步内容”。

看到 429 是什么？

429 通常表示请求过快。工具会尽量自动重试，你也可以稍等一会儿再继续同步或导出。

为什么“我的知识库”是空的？

请先同步一次内容和知识库。如果仍然为空，可能是开放平台暂时没有返回你的个人知识库列表，笔记列表仍可以按标签和关键词筛选。

图片会一起导出吗？

详情页会展示图文笔记里的图片预览。导出 Markdown 时会尽量保留图片链接，方便你后续整理。

刷新页面后还要重新加载吗？

工具会尽量恢复上次加载结果、筛选、选中项和详情。清理浏览器数据后，需要重新填写连接设置。

问题还是没解决？

可以到 GitHub 反馈问题。请描述你正在做什么、看到什么提示、使用什么浏览器；不要贴真实 API Key、Client ID 或 Token。

如果需要提交问题，请使用 GitHub Issue。

知识库内容整理

如果你的内容已经分散在不同知识库里，最省力的方式通常不是整库导出，而是先按知识库进入，再结合标签和关键词把范围收紧。

适合什么时候用？

当你想按主题、项目或资料来源分批整理内容，而不是把所有内容一次性混在一起处理时。

建议怎么开始？

先连接 API Key，再同步内容；如果知识库选项已经出现，就优先从知识库筛选开始，再叠加标签和关键词。

原文与摘要导出

Get2MD 更适合用来先预览，再决定保留原文、图片相关内容，还是只保留 AI 总结。这样导出的结果会更干净，也更适合后续归档。

这里能整理什么？

最直接的是原文、图片相关内容和 AI 总结。适合先打开详情确认，再决定下载哪一部分。

什么时候更适合导出？

当你需要长期备份、离线归档，或者准备迁移到 Obsidian、Notion 或本地文件夹时。

筛选后批量导出

如果你不是想导出单篇，而是想把一批相关内容一起带走，最适合的方式是先筛选，再批量下载，不用一篇篇重复操作。

这里能帮你做什么？

帮助你把同一批主题内容集中选中，再一次性导出原文或 AI 总结，适合阶段性备份和专题归档。

建议怎么用？

先用知识库、标签、关键词把结果缩到足够小，再使用“选择当前结果”做批量导出，会更顺手。
