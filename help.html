Help

遇到问题，先从这里排查

这份说明只保留用户真正会遇到的几类问题：同步、限流、知识库筛选、图片导出和本地配置。

同步失败怎么办？

  • 确认你已经填写 API Key 和 Client ID。
  • 确认当前 Get 账号有开放平台能力和会员权限。
  • 如果刚刚失败，可以等一会儿再点“同步过去所有笔记”或“同步最近笔记”。

看到 429 是什么？

429 通常表示请求过快。工具会尽量自动重试，你也可以稍等一会儿再继续同步或导出。

为什么“我的知识库”是空的？

请先同步一次笔记和知识库。如果仍然为空，可能是开放平台暂时没有返回你的个人知识库列表，笔记列表仍可以按标签和关键词筛选。

图片会一起导出吗？

详情页会展示图文笔记里的图片预览。导出 Markdown 时会尽量保留图片链接，方便你后续整理。

刷新页面后还要重新加载吗？

工具会尽量恢复上次加载结果、筛选、选中项和详情。清理浏览器数据后，需要重新填写接口设置。

问题还是没解决？

可以到 GitHub 反馈问题。请描述你正在做什么、看到什么提示、使用什么浏览器；不要贴真实 API Key、Client ID 或 Token。

如果需要提交问题，请使用 GitHub Issue。
