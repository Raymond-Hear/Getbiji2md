# 同步与笔记类型筛选

## 同步体验

- 首次启动后，自动按接口游标连续读取全部笔记。接口仍每次返回 20 条。
- 列表、详情和知识库请求共用串行队列，默认在请求结束后至少等待 1.1 秒。
- 频率限流时按指数退避或服务端 `Retry-After` 等待，并降低后续请求频率。
- 配额耗尽、永久错误、重复页或无效游标时暂停，保留已完成批次。
- 暂停等待当前请求结束；排队请求退出。已经读取的批次保留。
- 每批保存任务、笔记和游标到当前浏览器。刷新后点击“继续同步”接着读取。
- 列表按笔记 ID 复用未变化的卡片，只更新变化项，保留勾选、筛选和详情。
- 切换知识库优先使用已加载结果。历史笔记未同步完时，知识库结果也可能尚未齐全。

## 最近更新与完整同步

- 完成首次同步后，主按钮显示“检查最近更新”。从最新页检查到连续两页无变化时停止。
- 最近检查合并遇到的新增和修改，不保证发现更早历史笔记的修改或删除。
- “完整重新同步”读取全部列表，完成前保留旧结果，完成后更新完整快照以核对历史修改和删除。
- 接口文档未明确保证创建日期排序，因此时间筛选只用于本地结果，不据此提前结束同步。
- 首次同步仍受接口速度和配额限制。关闭页面后任务暂停，网站没有服务器后台同步。

## 类型筛选

独立支持文本、录音、链接、图文、视频、其他六类，依据 `note_type`、专用内容字段及系统类型标签识别。

类型单选，与知识库、标签、关键词、日期取交集。点击卡片类型也能筛选；选择当前结果后可批量导出。

系统标签中与六类名称完全一致的标签从标签筛选和卡片标签区移除，主题标签保留。不会修改接口笔记本身。

## 验证

运行 `node --test tests/sync.test.cjs` 验证千条同步、恢复、限流/配额、失败停止、请求队列、类型组合与完整核对。

运行 `node tests/preview-server.cjs`，打开 `http://127.0.0.1:8766/__preview/app.html` 可测试模拟千条笔记的页面交互。该地址使用模拟数据，不调用真实笔记接口。
