# 项目进度

## 当前产品方向

已确定采用本地优先 MVP 路线：

- 不做登录。
- 不做数据库。
- 不做 SaaS。
- 用户自己提供 API Key 和 Client ID。
- 凭证保存在用户当前浏览器本地。
- 项目方只托管网页，不保存用户笔记和密钥。

## 已完成

- 纯前端页面。
- API Key 和 Client ID 本地保存。
- 自动加载知识库和笔记。
- 按知识库筛选。
- 按标签筛选。
- 按关键词搜索。
- 单篇预览。
- 单篇 Markdown 下载。

- README 基础说明。
