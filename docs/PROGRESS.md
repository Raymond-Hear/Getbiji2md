# 项目进度

## 当前产品方向

已确定采用本地优先 MVP 路线：

- 不做登录。
- 不做数据库。
- 不做 SaaS。
- 用户自己提供 API Key 和 Client ID。
- 凭证保存在用户当前浏览器本地。
- 项目方只托管网页，不保存用户笔记和密钥。

## 已完成

- 纯前端页面。
- 独立落地页，用来介绍产品、使用方式和开源入口。
- 独立工具页，用来完成真实同步、筛选、预览和导出。
- API Key 和 Client ID 本地保存。
- 首次设置改为分步引导，降低新用户一次看到太多信息的压力。
- 同步我的笔记。
- 刷新页面后恢复上次结果和筛选状态。
- 按“我的知识库”筛选。
- 按标签筛选。
- 笔记列表支持一键选择当前筛选结果。
- 点击笔记卡片里的知识库，可快速切换为该知识库筛选。
- 点击笔记卡片里的标签，可快速切换为该标签的单选筛选。
- 当前筛选条件支持点击删除。
- 按关键词搜索。
- 单篇预览原文、AI 总结和图片。
- 单篇 Markdown 下载。
- 批量 zip 下载。
- 落地页展示项目源码入口和作者 GitHub 主页。
- V0.1 开源测试版说明和 GitHub Issue/PR 入口。
- 工具页头部升级为工作台式入口，突出同步、筛选、预览、导出的主路径。
- 工具页增加四步流程提示，降低首次进入时的理解成本。
- 落地页主张统一为“把 Get 笔记带回你的写作流”，和工具页保持一致。
- 落地页流程统一为设置、同步、筛选、导出四步。
- 笔记详情面板升级为预览与导出工作区，未选中笔记时会明确提示下一步。
- 单篇导出按钮在未选中笔记时禁用，避免用户误点。
- README 基础说明。

## 本轮补充

- 将页面拆分为落地页和工具页，让用户先了解产品，再进入导出流程。
- 统一落地页和工具页的视觉风格，减少两个页面之间的割裂感。
- 保留“我的知识库”筛选，弱化容易混淆的订阅库和笔记归属概念。
- 同步按钮调整为主要入口，用户点击后自动补齐当前范围内容。
- 同步过程使用右下角轻量进度提示，不再用大面积闪烁式加载。
- 页面刷新后尽量保留已加载结果、筛选、选中项和笔记详情。
- 当前筛选条件改为可点击删除，减少用户清理筛选的成本。
- 笔记卡片里的标签点击后进入单标签筛选，避免隐性多选造成困惑。
- 图文笔记支持在详情中预览图片，并在导出时保留图片链接。
- 落地页右上角增加项目源码和作者主页入口。
- V0.1 开源测试版增加 GitHub Issue/PR 引导。
- 设置弹窗改为逐步展示：准备信息、填写 API Key、填写 Client ID、确认保存。
- 工具页强化“写作流/知识管理”定位，减少开发工具感。
- 落地页补充本地处理、MIT 开源、图文笔记支持等简短信任标签。
- 详情信息从长文本改为可扫读标签，方便快速确认日期、范围、标签和图片数量。
- 笔记列表新增“选择当前结果”，方便用户在筛选后批量导出。
- 笔记卡片里的知识库名称改为可点击筛选，减少用户回到筛选区查找的成本。
- 接入 Vercel Web Analytics，用来观察公开站点访问和页面浏览情况。
- 空状态和加载失败状态增加直接操作按钮，用户可以从当前页面继续同步、清空筛选或检查设置。
- 移动端减少嵌套滚动，批量操作、设置弹窗和空状态按钮更适合单手点击。
- 落地页和工具页补充页面描述信息，主按钮改为更明确的“打开导出工具 / 接口设置”。
- 新增面向普通用户的独立隐私说明页，并从落地页和工具页提供入口。
- 新增 GitHub Issue/PR 模板，帮助用户反馈问题时避免暴露敏感凭证。
- 新增常见问题页，集中说明同步失败、429、知识库为空、图片导出和本地配置恢复。
- 补齐正式域名的 canonical、Open Graph URL、robots.txt 和 sitemap.xml。
- 补齐 Web App Manifest、theme-color、分享卡片图片和 Twitter card 元信息。
- 新增自定义 404 页面，避免用户访问错误路径时掉进默认错误页。
