# 首页与产品图素材清单

这份文档只回答两件事：

1. 你现在要给我接哪些图  
2. 这些图应该长什么样，才适合放进现在这套站点

## 放到哪里

把截图放到这里：

- `assets/homepage/screenshots/`

## 现在最需要的 6 张图

优先级从高到低如下。

### 1. 工具总览图

- 建议文件名：`homepage-tool-overview-desktop.png`
- 用途：放在首页靠前的位置，证明这个工具真实存在，不只是说明文字
- 要截到的内容：
  - `app.html` 顶部主区
  - 四步流程条
  - 左侧筛选区
  - 中间结果区
  - 右侧详情区
- 最好状态：
  - 已经同步出一些笔记
  - 页面是桌面宽屏
  - 不要弹出设置框

### 2. 笔记列表图

- 建议文件名：`notes-list-desktop.png`
- 用途：放在 Features 区块，展示“同步后能整理”
- 要截到的内容：
  - 4 到 8 条笔记
  - 标题清楚
  - 标签清楚
  - 最好能看出知识库或主题信息
- 最好状态：
  - 内容整齐
  - 不要一堆超长标题

### 3. 单篇详情预览图

- 建议文件名：`note-detail-preview.png`
- 用途：放在 Features 或内容深度说明区块，展示“不只是下载”
- 要截到的内容：
  - 一篇已选中的笔记
  - 原文内容区域
  - AI 总结区域
  - 如果有图片预览更好
- 最好状态：
  - 结构清楚
  - 不要整屏都是密密麻麻长文

### 4. 筛选后结果图

- 建议文件名：`filtered-results.png`
- 用途：放在 Workflow 或流程说明区块，展示“先筛再导出”
- 要截到的内容：
  - 至少一个已启用的标签或知识库筛选
  - 结果明显缩小后的列表
  - 最好能让人一眼看出“状态变了”
- 最好状态：
  - 不要和未筛选状态太像

### 5. 批量导出图

- 建议文件名：`batch-export-state.png`
- 用途：放在导出能力相关区块
- 要截到的内容：
  - 已勾选多篇笔记
  - 批量操作按钮可见
  - 原文导出 / AI 总结导出按钮清楚
- 最好状态：
  - 勾选数量不要太多
  - 画面不要显得很乱

### 6. 设置弹窗图

- 建议文件名：`settings-prepare-modal.png`
- 用途：放在信任感 / 上手说明相关区块
- 要截到的内容：
  - 设置弹窗第一步“准备信息”
  - 或 API Key / Client ID 输入那一步
- 最好状态：
  - 只截 1 到 2 个关键状态
  - 不要把整个引导都截完
  - 一定打码敏感信息

## 统一风格要求

你给我的截图，尽量符合这一套：

- 真实产品截图优先
- 先桌面图，再考虑移动端
- 内容干净，不要测试垃圾数据
- 中文文案可读，不要一屏全是字
- 同一批截图尽量保持相近缩放比例
- 敏感信息先打码
- 不要截浏览器收藏栏、桌面杂物、系统弹窗

## 这套站现在的视觉方向

为了让截图放进首页时不跳戏，建议素材尽量贴近当前页面气质：

- 深色主视觉 + 浅色内容面板
- 主强调色：橙色
- 辅助强调色：青绿色
- 整体更像“现代产品工具页”
- 不要太花
- 不要营销图感太重

一句话概括就是：

- `真实`
- `克制`
- `干净`
- `能看懂`
