# Get 笔记 Markdown 下载工具 PRD

## 1. 产品定位

Get 笔记 Markdown 下载工具是一个本地优先的导出工具，用来帮助用户把自己 Get 笔记账号里的原文内容和 AI 总结导出为 Markdown 文件。

当前版本不做 SaaS，不做用户登录，不做数据库。用户可以访问公开网页，也可以下载到本地或自行部署。API Key、Client ID 和笔记内容都只在用户自己的浏览器或设备中处理。

## 2. MVP 目标

- 让用户无需注册即可打开网页使用。
- 让用户自己填写 Get 笔记开放平台的 API Key 和 Client ID。
- 将凭证保存到当前浏览器本地，避免每次重复填写。
- 支持筛选、预览、单篇下载和批量打包下载。
- 明确告知用户：项目方不保存用户凭证和笔记内容。

## 3. 非目标

MVP 阶段暂不做以下能力：

- 用户账号系统。
- 数据库。
- 云端保存 API Key。
- 云端同步用户笔记。
- 多设备同步配置。
- 自动定时备份。
- 商业化订阅系统。

## 4. 目标用户

- Get 笔记会员用户。
- 想把笔记内容保存到 Obsidian、Notion、本地文件夹或个人知识库的人。
- 对隐私敏感，不希望把笔记内容和 API Key 上传到第三方服务器的人。
- 想使用一个开源、自部署、可审计工具的人。

## 5. 核心使用流程

1. 用户打开网页或本地 `index.html`。
2. 页面提示用户填写 API Key 和 Client ID。
3. 用户保存配置。
4. 凭证保存到当前浏览器的 localStorage。
5. 页面从用户浏览器直接请求 Get 笔记开放 API。
6. 用户筛选、搜索、预览笔记。
7. 用户下载单篇 Markdown，或批量下载 zip。
8. 用户可以随时清除本地保存的凭证。

## 6. 核心功能

- 接口设置：填写 API Key 和 Client ID。
- 本地保存：将配置保存在浏览器 localStorage。
- 一键清除：清除本地保存的 API Key 和 Client ID。
- 自动加载：保存配置后自动加载知识库和笔记。
- 筛选搜索：支持关键词、知识库、标签筛选。
- 内容预览：查看单篇笔记原文和 AI 总结。
- 单篇下载：下载单篇原文或 AI 总结 Markdown。
- 批量下载：选择多篇笔记并打包为 zip。
- 隐私提示：明确说明无需登录、无数据库、凭证仅保存在本地。

## 7. 风险与限制

- Get 笔记开放 API 需要会员和有效开放平台凭证。
- 如果开放 API 不允许浏览器跨域请求，公开网页模式可能失败。
- 用户清理浏览器数据后，需要重新填写 API Key 和 Client ID。
- 不同设备或不同浏览器之间不会同步配置。
- 大批量导出可能受接口限流影响，需要重试和更清晰的进度提示。
