# Get 笔记 Markdown 下载工具 PRD

## 1. 产品定位

Get 笔记 Markdown 下载工具是一个本地优先的导出工具，用来帮助用户把自己 Get 笔记账号里的原文内容和 AI 总结导出为 Markdown 文件。

当前版本不做 SaaS，不做用户登录，不做数据库。用户可以访问公开网页，也可以下载到本地或自行部署。API Key、Client ID 和笔记内容都只在用户自己的浏览器或设备中处理。

## 2. 当前版本

当前版本：V0.1 开源测试版。

V0.1 的重点不是做一个完整账号系统，而是先让用户可以稳定完成“同步、筛选、预览、导出”这一条主路径。页面已经拆分为落地页和工具页：落地页负责介绍产品、开源入口和使用方式；工具页负责真实导出操作。

## 3. MVP 目标

- 让用户无需注册即可打开网页使用。
- 让用户自己填写 Get 笔记开放平台的 API Key 和 Client ID。
- 首次设置采用分步引导，不一次性展示所有配置说明。
- 将凭证保存到当前浏览器本地，避免每次重复填写。
- 支持筛选、预览、单篇下载和批量打包下载。
- 支持刷新页面后恢复上次结果和筛选状态。
- 明确告知用户：项目方不保存用户凭证和笔记内容。
- 引导用户在 GitHub 查看源码、访问作者主页、提交 PR。

## 4. 非目标

MVP 阶段暂不做以下能力：

- 用户账号系统。
- 数据库。
- 云端保存 API Key。
- 云端同步用户笔记。
- 多设备同步配置。
- 自动定时备份。
- 商业化订阅系统。
- 在页面内展示复杂的开发说明。

## 5. 目标用户

- Get 笔记会员用户。
- 想把笔记内容保存到 Obsidian、Notion、本地文件夹或个人知识库的人。
- 对隐私敏感，不希望把笔记内容和 API Key 上传到第三方服务器的人。
- 想使用一个开源、自部署、可审计工具的人。

## 6. 核心使用流程

1. 用户打开落地页，了解工具用途、隐私边界和开源入口。
2. 用户点击“立即开始”进入工具页。
3. 页面用分步引导提示用户准备 API Key 和 Client ID。
4. 用户按步骤填写 API Key。
5. 用户按步骤填写 Client ID。
6. 用户确认并保存配置。
7. 凭证保存到当前浏览器本地。
8. 页面从用户浏览器直接请求 Get 笔记开放 API。
9. 用户同步笔记，并在同步后继续浏览已有结果。
10. 用户按“我的知识库”、标签、关键词筛选笔记。
11. 用户点击笔记列表里的标签，可快速切换为该标签的单选筛选。
12. 用户点击“当前筛选”里的条件，可直接删除对应筛选。
13. 用户预览笔记原文、AI 总结和图片。
14. 用户下载单篇 Markdown，或批量下载 zip。
15. 用户可以随时清除本地保存的凭证。

## 7. 核心功能

- 接口设置：填写 API Key 和 Client ID。
- 分步设置：首次进入时按步骤完成准备、API Key、Client ID、确认保存。
- 本地保存：将配置保存在当前浏览器本地。
- 一键清除：清除本地保存的 API Key 和 Client ID。
- 同步笔记：点击“同步我的笔记”后拉取当前账号内容。
- 状态恢复：刷新页面后尽量保留已加载结果、筛选、选中项和详情。
- 知识库筛选：只保留“我的知识库”筛选，不再混放订阅库或书本归属。
- 标签筛选：支持从下拉中选择标签，也支持点击笔记卡片标签快速切换。
- 当前筛选：已启用条件以 chip 形式展示，点击即可移除。
- 关键词搜索：支持按标题、标签和已加载正文内容搜索。
- 内容预览：查看单篇笔记原文、AI 总结和图片。
- 单篇下载：下载单篇原文或 AI 总结 Markdown。
- 详情导出：打开笔记后，详情面板展示可扫读信息，并提供单篇导出动作。
- 批量下载：选择多篇笔记并打包为 zip。
- 隐私提示：明确说明无需登录、无数据库、凭证仅保存在本地。
- 开源入口：落地页展示项目源码、作者主页和 PR 入口。
- 工具工作台：进入工具页后，用清晰的主张、流程提示和核心按钮引导用户完成同步与导出。
- 统一产品主张：落地页和工具页都围绕“把 Get 笔记带回写作流”表达。

## 8. 体验原则

- 页面文案优先面向普通用户，不展示复杂的开发说明或补丁式解释。
- 筛选行为要符合直觉：点击标签就是进入该标签范围，点击已选条件就是删除条件。
- 同步过程尽量不打断用户操作，不使用大面积闪烁或占位加载。
- 关键动作要放在用户容易看到的位置，不要求用户反复滚动到底部。
- 错误提示要告诉用户下一步该怎么做，避免把技术原因直接丢给用户。
- 页面要减少“开发面板感”，让用户一眼知道自己下一步要做什么。

## 9. 风险与限制

- Get 笔记开放 API 需要会员和有效开放平台凭证。
- 如果开放 API 不允许浏览器跨域请求，公开网页模式可能失败。
- 用户清理浏览器数据后，需要重新填写 API Key 和 Client ID。
- 不同设备或不同浏览器之间不会同步配置。
- 大批量导出可能受接口限流影响，需要重试和更清晰的进度提示。
